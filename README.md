## Web tools I build

These are small, task-focused tools available in the browser.

| Tool | What it helps with |
| --- | --- |
| [FitToKB](https://fittokb.com/) | Resize and compress images for file-size limits. |
| [BestTimeCard](https://besttimecard.com/) | Calculate work hours, breaks and gross-pay scenarios. |
| [GPACalculate](https://gpacalculate.net/) | Calculate GPA and plan grades for a target. |
| [DemandLetterKit](https://demandletterkit.com/) | Prepare demand-letter drafts with practical examples and state resources. |
| [BillOfSaleTool](https://billofsaletool.com/) | Prepare bills of sale with item and state guidance. |
| [BedtimeCalc](https://bedtimecalc.net/) | Explore bedtime and wake-up schedules with clear estimate assumptions. |

The document tools provide general information, not legal representation. Sleep results are planning estimates, not medical advice.
